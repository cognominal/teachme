# PyTorch, written out, batched over leading dims (batch, heads)
def attention(Q, K, V, mask=None):            # (..., T, dk), (..., T, dk), (..., T, dv)
    dk = Q.shape[-1]
    scores = Q @ K.transpose(-2, -1) / dk ** 0.5
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))   # 0 = may not look
    return torch.softmax(scores, dim=-1) @ V  # (..., T, dv)

For a causal model, the mask is torch.tril(torch.ones(T, T)) — or you skip it entirely and ask the fused kernel: F.scaled_dot_product_attention(Q, K, V, is_causal=True). Same numbers to within 3.6 × 10−7 in float32 (bit-identical in float64), measured in this workspace.

# Multi-head (lesson 03): the same five steps, H times, over slices of the width
def multi_head_attention(Q, K, V, H):            # (T, C) x3
    Qh = Q.view(T, H, C // H).transpose(0, 1)    # (H, T, dh)
    Kh = K.view(T, H, C // H).transpose(0, 1)
    Vh = V.view(T, H, C // H).transpose(0, 1)
    scores = Qh @ Kh.transpose(-2, -1) / math.sqrt(C // H)   # scale by dh, not C
    scores = scores.masked_fill(torch.tril(torch.ones(T, T)) == 0, float("-inf"))
    weights = torch.softmax(scores, dim=-1)      # (H, T, T), every row sums to 1
    return (weights @ Vh).transpose(0, 1).reshape(T, C)      # reshape, not view

With H = 1 this is lesson 02 exactly (to float32 noise, measured 3 × 10−8). The heads are independent until a learned WO mixes the concatenation — in nanoGPT, y = self.c_proj(y).

Sanity checks you can do by hand

  • One token: with T = 1 the only weight is 1, so the output equals the single value row. Any correct implementation reproduces this.
  • Identical rows: if every key row is the same, every weight in a row is 1/T — a plain average.
  • Sharpness: multiply the scaled scores by a constant c and the distribution sharpens as c grows; the scale 1/√dk exists to keep c ≈ 1.
  • Convexity: every output cell must lie between the smallest and largest value in that column of V. A weighted average can never leave the range of what it averages.
  • Causal shape: row i of the weights has exactly i+1 non-zero entries and zeros after them; blocked cells are exactly 0.0, not 1e-8.
  • Row 0 under a causal mask: with only itself visible, the output row equals V[0] exactly. If it does not, the diagonal is missing from your mask.
  • Leak test: replace a row of V with something absurd; every output row before it must be bit-identical, and the row at that position must change.

Where this came from

  • Vaswani et al., Attention Is All You Need, §3.2.1 and Figure 2 — the definition everything else paraphrases. Footnote 4 on that page is the scaling argument.
  • The same paper, §3.2.2 — multi-head in two paragraphs: the h learned projections, "h = 8 parallel attention layers … d_k = d_v = d_model/h = 64", the cost claim, and "Multi-head attention allows the model to jointly attend to information from different representation subspaces at different positions. With a single attention head, averaging inhibits this." Table 3 row (A) prices getting it wrong.
  • Shazeer, Fast Transformer Decoding: One Write-Head is All You Need (2019) and Ainslie et al., GQA (2023) — the variants you will meet in real checkpoints: keys and values shared across all heads (MQA), or across groups of them (GQA), to shrink what generation has to reload.
  • karpathy/nanoGPT, model.py — CausalSelfAttention: the triangle registered as a buffer and sliced to the sequence length, the masked_fill, and the is_causal=True fast path.
  • PyTorch scaled_dot_product_attention — the fused production kernel; same maths, better memory behaviour, and is_causal / attn_mask semantics.
