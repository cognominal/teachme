# teachme

Course material for learning transformer attention from scratch. Two independent
attempts at teaching the same subject, kept side by side because they make
different bets about how to teach it.

| hierarchy | generated by | shape |
|---|---|---|
| `attention/` | a **teachme prompt** | notes + runnable labs + numeric verification |
| `attention-matt/` | **Matt Pocock's `/teachme` skill** | mission + HTML lessons + retrieval-practice loop + grader |

## `attention/` — prompt-generated

A reading-first course: four notes (`notes/01-mechanics.md` →
`04-modern.md`) backed by code that prints the numbers the notes talk about.

- `code/attn.py` — scaled dot-product attention from scratch in NumPy, including
  masking, causal masks and sliding windows.
- `code/lab.py` — 13 runnable demonstrations, selectable by name
  (`python code/lab.py softmax scale causal`).
- `code/verify.py` — 30 numerical checks; PyTorch is used only as an
  *independent* implementation to check the NumPy one against.
- `code/tiny_transformer.py` — trains a real toy transformer and inspects its heads.
- `exercises/` — problems with self-checking solutions.

Start with `attention/README.md`, which has a 15-minute / 1-hour / weekend
reading plan.

## `attention-matt/` — skill-generated

A session-based tutor: `MISSION.md` fixes the learner profile and the success
criteria, `learning-records/` logs what has actually been learned and why the
plan changed (e.g. the substrate switch from JS to PyTorch), and each lesson is a
self-contained HTML page with exercises graded by a CLI.

- `lessons/` — `0000-matrices-for-attention.html` (plain JavaScript), then `0001-attention-as-a-weighted-average.html`, `0002-the-mask-and-the-scale.html`, `0003-several-weighted-averages.html`
- `reference/` — glossary, matrix ops, Python-for-JS-devs, scaled dot-product attention
- `exercises/0001_attention.py` … `0003_multihead.py` + `exercises/solutions/` — the code the learner edits, shipped as stubs
- `bin/lesson`, `bin/grade`, `bin/grader` — serve a lesson, grade one exercise, run the grading server; `bin/record` writes the next learning record
- `tools/grader/` — the grader core, per-lesson checks, CLI and HTTP server
- `tools/check_lessons.py` — syntax-checks every inlined lesson script and asset
- `MISSION.md`, `NOTES.md`, `RESOURCES.md`, `HOW.md`, `README.md` — mission, working notes, sources, and how the machinery works

The loop is: `./bin/grader` to serve the pages, read a lesson, edit `exercises/<lesson>.py`, run `./bin/grade <lesson>` (or click the page's button, which runs the same checks and shows your script's own output). `learning-records/` is untracked, so it may be absent; `./bin/record` creates it. `attention-matt/README.md` has the short version of all of this.

## Setup

Each hierarchy has its own untracked `.venv` (see `.gitignore`) and there is no lockfile, so
recreate the one you need. Both were built with [uv](https://docs.astral.sh/uv/):

```bash
# attention-matt/ — torch + numpy, on CPython 3.13.16
uv venv --python 3.13 attention-matt/.venv
uv pip install --python attention-matt/.venv/bin/python \
    --index-url https://download.pytorch.org/whl/cpu torch
uv pip install --python attention-matt/.venv/bin/python numpy   # torch warns at import without it
```

`attention/.venv` is CPython 3.12.15 and needs numpy 2.5.4 as well. The `--index-url` matters:
PyPI's `torch` resolves to the CUDA build and pulls the whole `nvidia-*` stack, while the CPU index
resolves to `torch==2.14.1+cpu` and six small pure-Python dependencies. Note that uv-built venvs
contain no `pip` (`uv pip install --python <venv>/bin/python …` is the equivalent). Everything runs
on CPU. `attention-matt/README.md` has the longer version, including the stdlib-venv fallback.
