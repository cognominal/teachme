# teachme

Course material for learning transformer attention from scratch. Two independent
attempts at teaching the same subject, kept side by side because they make
different bets about how to teach it.

| hierarchy | generated by | shape |
|---|---|---|
| `attention/` | a **teachme prompt** | notes + runnable labs + numeric verification |
| `attention-matt/` | **Matt Pocock's `/teachme` skill** | mission + HTML lessons + retrieval-practice loop + grader |

## `attention/` — prompt-generated

A reading-first course: four notes (`notes/01-mechanics.md` →
`04-modern.md`) backed by code that prints the numbers the notes talk about.

- `code/attn.py` — scaled dot-product attention from scratch in NumPy, including
  masking, causal masks and sliding windows.
- `code/lab.py` — 13 runnable demonstrations, selectable by name
  (`python code/lab.py softmax scale causal`).
- `code/verify.py` — 30 numerical checks; PyTorch is used only as an
  *independent* implementation to check the NumPy one against.
- `code/tiny_transformer.py` — trains a real toy transformer and inspects its heads.
- `exercises/` — problems with self-checking solutions.

Start with `attention/README.md`, which has a 15-minute / 1-hour / weekend
reading plan.

## `attention-matt/` — skill-generated

A session-based tutor: `MISSION.md` fixes the learner profile and the success
criteria, `learning-records/` logs what has actually been learned and why the
plan changed (e.g. the substrate switch from JS to PyTorch), and each lesson is a
self-contained HTML page with exercises graded by a CLI.

- `lessons/` — `0000-matrices-for-attention.html`, `0001-attention-as-a-weighted-average.html`
- `reference/` — glossary, matrix ops, Python-for-JS-devs, scaled dot-product attention
- `exercises/0001_attention.py` + `exercises/solutions/` — the code the learner edits
- `bin/lesson`, `bin/grade`, `bin/grader` — serve a lesson, grade one exercise, run the grading server
- `tools/grader/` — the grader core, per-lesson checks, CLI and HTTP server
- `RESOURCES.md`, `NOTES.md` — source material and working notes

The loop is: read the lesson, edit `exercises/<lesson>.py`, run `./bin/grade <lesson>`.

## Setup

Virtualenvs are not tracked (see `.gitignore`) and there is no lockfile, so
recreate them per hierarchy:

```bash
python -m venv .venv
.venv/bin/pip install numpy torch   # attention/ was built against numpy 2.5.4, torch 2.14.1+cpu
```

Everything runs on CPU.
